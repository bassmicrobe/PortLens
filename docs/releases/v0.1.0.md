PortLensの初回公開版です。MacのUSB・Thunderbolt／USB4機器が、どのバスやハブにつながっているかを接続図と一覧で確認できます。

## ダウンロード

- **[PortLens-0.1.0-universal.zip](https://github.com/bassmicrobe/PortLens/releases/download/v0.1.0/PortLens-0.1.0-universal.zip)** — macOS 14以降、Appleシリコン・Intel Mac対応
- [SHA-256チェックサム](https://github.com/bassmicrobe/PortLens/releases/download/v0.1.0/PortLens-0.1.0-SHA256SUMS.txt)

ZIPを展開し、`PortLens.app`をApplicationsフォルダにコピーしてください。XcodeやCommand Line Toolsは不要です。

## 主な機能

- USBとThunderbolt／USB4の接続図・機器一覧
- 機器までの経路の強調表示、下流の展開・折りたたみ、ズーム
- 機器名・メーカー・位置IDでの検索と詳細表示
- 自分用の表示名、経路のコピー、JSON書き出し
- 手動更新と任意の10秒ごとの自動更新
- ローカルでの情報取得とデモ表示

## 署名と初回起動

アドホック署名付きです。Developer ID署名とAppleの公証はまだ行っていません。初回起動時にmacOSが開発元を確認できない旨を表示する場合があります。入手元とチェックサムを確認し、必要に応じて[Appleの公式案内](https://support.apple.com/ja-jp/102445)を参照してください。

図はmacOSが報告する論理的な接続関係です。USBとThunderboltは別々に表示し、実物のポート位置や空きポートを推測する機能はありません。

## 確認内容

- 接続情報・プライバシー・図の配置・ズーム計算の18件の共通検証
- ZIPを展開したアプリの署名と、arm64・x86_64の両アーキテクチャを確認
- AppleシリコンとRosetta 2でデモスナップショット取得が一致することを確認
- 明暗それぞれのロゴがアプリに同梱されていることを確認
